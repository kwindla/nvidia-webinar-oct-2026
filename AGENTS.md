# Project instructions

- Use Python 3.12 only and `uv` for Python dependencies and commands.
- Use the Pipecat context-hub MCP for Pipecat documentation, APIs, and best practices.
- With every project change, clean up obsolete code/configuration and update
  `README.md` to match the actual implementation. Keep it concise but include
  all steps needed to install dependencies, start servers, and run every demo.
- Keep credentials, downloaded weights, vendor checkouts, binaries, and generated
  artifacts out of source control. Read Hugging Face credentials from `HF_TOKEN`.
